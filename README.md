Nara Organics is a direct-to-consumer organic infant-formula brand, surfaced as a portfolio company of Initialized Capital and profiled in the API Evangelist network. It is not a traditional API provider, but its Shopify storefront at nara.com exposes a modern agent-native commerce surface: a published Universal Commerce Protocol (UCP) MCP endpoint for agent-driven catalog search, cart, and buyer-approved checkout; a Shopify Customer Account OIDC provider; and /llms.txt + /agents.md agent instructions covering the read-only product surface and the Shop Pay flow. The company is currently managing a voluntary infant-formula recall communicated through its storefront.

**Areas:** Company · Consumer · Commerce · Retail · Shopify · Agentic Commerce · Universal Commerce Protocol · MCP · Infant Formula

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Nara Organics: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
